# Task spec

## 背景

生产环境确认（p069）：即使发件人已放行，大量邮件正文图片仍碎图。根因不是代理链路——L3 实测生产 CSP 下代理端点返回的真实图片可成功解码（`naturalWidth` 160/512，零 CSP 违规）——而是服务端图片 URL 提取缺陷：Google 通知邮件 `<img>` 使用 HTML5 合法无引号属性（`src=https://...`），手写正则要求引号，导致 `remote_images` 映射为空；另有 HTML 实体、协议相对 URL、错误分类混淆、SVG 误伤与单 IP 无回退等同类缺陷。

全库量化（L1，19897 封有正文）：558 封提取为 0（全碎）、2519 封部分漏提取、2874 封实体不一致风险、2 封仅协议相对。L2 真实试拉 800 URL：556 成功，另有 DNS 失效被误报为 SSRF 拦截 22、上游 4xx/409 与超时混同为 502。

## 契约区

### 范围

- 服务端图片 URL 提取改为 HTML5 属性解析语义，与前端 DOMParser 取值保证一致：
    - 支持无引号、单引号、双引号混用；
    - 对属性值执行字符引用（HTML 实体）解码；
    - 协议相对 URL（`//host/path`）规范化为 `https://host/path`；
    - 覆盖 `<img src>` 与行内 `style` 中的 `background-image: url(...)`；
    - 去重、单 URL 长度上限、单封上限 200 保持。
- 前端重写匹配与后端规范化对齐：对 DOM 取到的 `src` / 背景 URL 做相同规范化（协议相对补全）后再匹配映射表。
- 代理端点错误分类可区分（不泄露内部细节）：
    - 非法目标 URL 参数 → 400；
    - Token 无效 → 401；
    - 未放行 → 403；
    - 消息不存在 → 404；
    - 上游非 2xx → 502；
    - DNS 解析失败、连接失败、TLS 失败 → 502；
    - 连接/读取超时 → 504；
    - 超出 10 MiB → 413；
    - 非安全位图或含危险内容 → 415。
- 多 IP 回退：DNS 解析出的全部安全 IP 按 IPv4 优先排序逐个尝试连接，受总超时预算约束；单个 IP 不可达不得直接失败。
- SVG 安全放行：合法 SVG（`image/svg+xml`）允许代理返回，保持 `nosniff` 与 `Content-Security-Policy: default-src 'none'`；含脚本、事件处理器、外部引用或嵌入对象的 SVG 仍按 415 拒绝。
- 回归保障：既有 SSRF 防护、大小上限、超时、Token 签名与实时撤销行为不变。

### 非范围

- 上游真实返回 404/403/409/超时或域名已失效的图片（浏览器直连同样失败），不视为缺陷、不做特殊兜底。
- 不做服务端图片持久化缓存。
- 不允许 SVG 以外的非位图格式（如 BMP/TIFF/AVIF）——本 task 只补齐已确认的 SVG 误伤。
- 不改变主应用、桌面端与正文沙箱的 CSP 基线。

- [ ] AC-001：含无引号 `<img src=https://host/x.png>` 的邮件放行后，服务端返回该图片的代理映射，真实浏览器中图片解码成功（`naturalWidth > 0`），控制台零 CSP 报错。
- [ ] AC-002：属性值含 HTML 实体（如 `src="https://host/x.png?a=1&amp;b=2"`）的图片，前端重写命中同一代理 URL，浏览器解码成功；服务端提取的 URL 与 DOM 解析值一致（无实体残留）。
- [ ] AC-003：协议相对图片地址（`src="//host/x.png"`）被规范化为 `https://host/x.png` 并签发代理映射，前端重写命中，图片解码成功。
- [ ] AC-004：行内 `style` 中 `background-image: url(...)` 的无引号、实体、协议相对三种形态同样被提取、规范化并重写。
- [ ] AC-005：代理端点在可观察响应上区分失败类别：DNS 失败/连接失败/TLS 失败返回 502，上游非 2xx 返回 502，连接或读取超时返回 504，超限返回 413，非安全位图返回 415，非法目标 URL 返回 400，且响应体不泄露内部 IP、异常栈或目标完整 URL。
- [ ] AC-006：当域名解析出多个安全 IP 且首个 IP 不可达时，代理自动尝试后续 IP；在模拟环境中成功返回图片而非报错。
- [ ] AC-007：合法 SVG 图片经代理返回并可在 CSP `img-src 'self'` 下显示；含 `<script`、事件处理器、外部 `href`/`xlink:href` 或 `<foreignObject` 的 SVG 返回 415 且不返回图片字节。
- [ ] AC-008：既有安全行为不回归：私网/回环/云元数据目标被拒，超 10 MiB 断开，Token 篡改 401，撤销白名单后 403。
- [ ] AC-009：以生产 Google 通知邮件原文形态（无引号多图）为夹具的全库回归抽样中，服务端提取数量等于正文实际外部图片数量，且抽样邮件在真实 CSP 下无碎图。

## 上下文区

- 来源：`p069`（2026-10-31 生产复现，L1 全库量化 + L2 真实试拉 + L3 生产 CSP 解码验证）；`d003`（零出网 CSP 基线）。

### 有意不测

- 上游服务端真实 404/403/409、连接超时与已失效域名：属外部环境，浏览器直连同样失败。
- GFW / 路由导致的跨境不可达：非代码缺陷。

### 测试策略

- 后端单测：HTML5 属性提取矩阵（无引号/单双引号/实体/协议相对/大小写/混合）、规范化一致性、错误分类、多 IP 回退、SVG 危险内容拒绝。
- 后端集成：真实 PostgreSQL + FastAPI，覆盖状态码映射与放行/撤销流程不回归。
- 前端单测：`rewriteRemoteImages` 对规范化后 key 的匹配（实体、协议相对、空白）。
- Playwright E2E：stub 夹具新增无引号 + 实体 + 协议相对邮件，在真实 CSP 下断言 `naturalWidth > 0` 与零 CSP 违规；全栈 E2E 抽取生产原文形态断言提取数量。

### 风险与回退

- 风险：SVG 放行扩大攻击面；通过保持 `nosniff`、`default-src 'none'` CSP 与危险内容拒绝清单控制；`<img>` 上下文本身禁止脚本与外部引用。
- 风险：多 IP 回退延长最坏耗时；通过总超时预算与 IPv4 优先控制。
- 回退：前端/后端改动均为纯逻辑修复，无数据迁移；回退即恢复上一镜像（`rollback-` 标签）。

### 依赖与约束

- 不新增第三方运行时依赖（维持容器最小依赖约束，参考 t068 部署教训）。
- 保持正文沙箱 CSP `img-src 'self' data: cid:` 不变。
