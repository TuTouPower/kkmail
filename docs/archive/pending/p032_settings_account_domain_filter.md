# p032 设置页账号列表增加域名筛选下拉项

- 来源：用户提出
- 内容：
    1. 当前现状：设置页账户管理工具栏（`SettingsModal`）仅提供搜索框、分组筛选（所有分组/未分组/具体分组）与同步状态筛选（全部状态/已启用/已暂停/同步异常），当账号较多时无法按邮箱域名快速聚焦。
    2. 目标方案：
        - 在账户管理工具栏增加域名筛选下拉框（如“所有域名”及从已有账号列表中动态提取去重、按字母排序的邮箱域名选项，如 `qq.com`、`163.com`、`gmail.com` 等）；
        - 账户列表过滤逻辑联动更新：支持按所选域名筛选账号，并与既有的搜索框、分组筛选、状态筛选条件组合生效；
        - 全选与批量操作逻辑（移动分组、同步、启用/暂停同步）自动适配包含域名筛选在内的当前过滤结果；
        - 补充 `SettingsModal` 相应单测用例，验证域名筛选单独生效及多条件组合筛选表现。
- 处理：main
