# p015 设置中支持配置账号图标展示方式（不展示/品牌图标/首字母）

- 来源：用户提出
- 内容：
    1. 在设置面板（设置 -> 外观或通用设置）增加“账号图标显示风格”选项；
    2. 提供三种模式：
        - `none`（不展示账号图标）：隐藏侧栏与账户列表中的前置圆点/图标，仅展示邮箱地址纯文本；
        - `brand`（展示官方品牌图标）：根据邮箱域名与协议（@outlook、@163、@qq、@gmail 等）智能展示对应的官方品牌标识/色彩；
        - `initials`（展示邮箱账号首字母）：根据邮箱用户名或前缀首字母生成标准化单字徽标；
    3. 配置项保存在本地偏好或用户设置中，侧边栏（Sidebar）与设置页账号列表统一响应变化。
