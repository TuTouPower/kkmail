# p043 侧栏账号列表新增搜索按钮支持按邮箱过滤账号

- 来源：用户提出
- 内容：
    1. 布局位置：
        - 在侧边栏“账号列表”分栏标题行中，位于“新建分组”图标按钮（`FolderPlus`）的左侧，新增一个搜索图标按钮（`Search` 图标，`aria-label="搜索账号"`，`title="搜索账号"`）。
    2. 交互体验：
        - 点击该搜索按钮后，展开或激活侧栏账号搜索输入框（可内嵌于标题栏下方或展开为行内输入框，支持自动聚焦）；
        - 提供便捷的退出/清除机制（例如按 `Esc` 键、点击清空按钮或再次点击搜索图标时关闭搜索栏并恢复全局视图）；
    3. 过滤逻辑：
        - 输入搜索关键词时，实时按邮箱地址（以及账号显示名称/域名）过滤侧栏展示的账号；
        - 保留匹配账号的层级结构（所在分组保持展开），过滤隐藏不匹配的账号；若未搜到匹配结果展示友好的空态提示；
        - 清空搜索关键词后恢复用户原有的展开与排序状态。
