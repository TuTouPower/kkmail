## Strengths

- Electron 基线扎实：`windowOptions.js` 同时开 `contextIsolation: true`、`sandbox: true`、`nodeIntegration: false`、`webviewTag: false`；`preload.js` 只暴露 platform/versions，无 IPC 通道；`hardening.js` CSP 无通配符、权限仅放行主框架本源的 `clipboard-sanitized-write` 且有成套边界测试。
- 子进程环境治理有设计：`startup.js` 用 allowlist `scrubEnv` + audited `SIDECAR_CONFIG_KEYS`，`collectSidecarExtras` 中 launcher 的 `baseExtras` 优先、父环境不能覆盖 DB URL/端口；后端日志经 `redactSecrets` 脱敏后才落盘；实例 token 用 `crypto.randomBytes(24)` 并在 `/health` 校验回显。

- 邮件 HTML 防线分层：`mailBody.ts` DOMPurify 禁标签/协议 + srcdoc 内联严格 CSP（`default-src 'none'`）+ iframe sandbox 仅 `allow-popups*`，远图默认关；链接统一被 hook 加 `rel="noopener noreferrer"`。
