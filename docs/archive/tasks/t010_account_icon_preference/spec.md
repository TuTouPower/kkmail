# Task spec

## 背景

p015 要求可配置账号图标。当前 mailStore 只有主题和宽度偏好，Sidebar 与 SettingsModal 固定使用 providerBadge/providerColor，根据 provider 名称产生字母圆点，无法选择隐藏、品牌或账号首字母。

## 契约区

### 范围

- 设置外观页增加账号图标展示模式 none / brand / initials，存入现有本地偏好并立即生效。
- 侧栏收藏账户、账号树节点与设置账号列表统一响应；隐藏模式不留下图标占位。
- 品牌识别覆盖 Gmail、Outlook/Hotmail/Live、163/126/NetEase、QQ 等现有常见服务商；使用随包静态资源。

### 非范围

- 不扩展服务端账户设置 API，不新增上传头像、跨设备同步、在线头像服务或主题皮肤。
- 不调整账号排序、分组颜色配置、目录导航或邮箱凭据行为。

### 验收标准

只写可观察、可独立验证的行为；每条使用稳定且不复用的 `AC-NNN`。需真实部署或人工环境验证时在编号前加 `[deploy]`。技术选型不作为行为 AC。

- [ ] AC-001：设置外观页提供“不展示 / 品牌图标 / 首字母”三种可访问选项；首次无偏好时默认 brand，修改即时反映至所有账号展示位置，刷新后保留选择，旧本地偏好中的主题和宽度保持不变。
- [ ] AC-002：none 模式移除账号前置圆点/图标及专属占位，保留邮箱地址、折叠控件和未读角标，账号点击区域仍可用。
- [ ] AC-003：brand 模式对 Gmail、Outlook/Hotmail/Live、163/126 与 QQ 账号使用可识别的对应品牌标识；即使用通用 imap 协议也能按精确邮箱域名匹配，不因域名包含 gmail/outlook 等子串而误识别；未知域名仅在明确 gmail/graph 提供商时采用对应品牌，其余显示通用邮箱图标。
- [ ] AC-004：initials 模式从邮箱 @ 前用户名首个非空字符生成大写单字符徽标，Unicode 字符不截成半个代理对，空或异常输入显示通用邮箱图标；同一账号在侧栏各入口与设置列表保持一致。
- [ ] AC-005：切换模式不触发外部图标、头像或邮件服务网络请求；品牌资源本地随包加载，亮暗两种主题均清楚可辨，图标不覆盖或截断已有账号名称及未读数。

### 有意不测

- 不测服务商在线品牌资源可用性；运行时不从外站取图，以本地资源和构建加载测试替代。

### 测试策略

- store 测试覆盖默认值、三模式更新、重新加载恢复及旧偏好数据不受损；不新增服务端状态。
- 用品牌映射参数化测试覆盖真实域名、大小写、相似恶意域名、IMAP 与显式 gmail/graph provider，以及未知服务商。
- Sidebar 与 SettingsModal 组件测试覆盖三模式统一更新、none 无占位和首字母 Unicode/异常输入。
- 浏览器亮暗主题和窄侧栏截图复核；构建产物检查本地品牌资源路径，拦截网络验证切换不请求外站。

### 风险与回退

- 风险：仅按 provider 推断会把 IMAP 邮箱识别错；远程头像泄露账号和阅读上下文；移除 account-dot 若误删折叠控件会破坏目录导航。
- 回退：回退执行 commit 恢复固定徽标，保留其他本地偏好；新图标偏好键可保留为无害未读取字段，无需清空本地存储。
