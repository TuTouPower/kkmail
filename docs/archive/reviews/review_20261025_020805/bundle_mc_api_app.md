## Strengths

- Auth is applied uniformly: accounts/mail/SSE routers are mounted with `Depends(require_auth)`, CSRF uses `secrets.compare_digest` with an API-key bypass that is explicit, and login has a failure limiter with Retry-After (spec AC-001/002/005 shape is respected at this layer).
- Attachment access is well-built: UUID-only route, explicit by-path rejection endpoint, RFC 5987 `Content-Disposition` built by a dedicated sanitizer (`http_headers.py`), streaming decrypt instead of materializing blobs, and `X-Content-SHA256` on the response.
- Keyset pagination in `queries.list_messages_keyset` handles NULL sort_time correctly in both directions (spec AC-014) and hydrates account emails in one batch query; search hydration preserves rank order.
- Folder-stats semantics preserve "unknown" (`unread_count=None` when any message state is unknown) end-to-end through global/group aggregates (spec AC-025), and mutations recompute stats transactionally with outbox events.
- Remote-ops coalescing uses a savepoint for the idempotency-key insert race, and `mark_remote_operation` redacts+truncates stored errors.
- SSE replay design is careful: subscribe-before-replay, dedupe by event id, resync hints for malformed/ahead/too-large/truncated replays, and a bounded dedupe set.
- OpenAPI contract is enforced by a canonical byte-comparison test against `schemas/openapi.json`; no drift was found between the committed schema's route inventory and the routers in this unit.
- Worker claim verification (owner + locked_at token re-check in `_tick`) and the "worker must not mark_dispatched" outbox discipline show real fencing awareness.
