# 007 持续集成 (CI) 分层门禁与发布边界隔离（t023）（2026-10-22）

- **决策**：创建只读权限的 GitHub Actions 工作流（`ci.yml` 和 `scheduled.yml`），禁止工作流申请写发布/镜像/标签权限；
- **分层**：
    1. PR 与 Push 必跑门禁：模板契约、前端全套（lint/type/unit/OpenAPI/build/轻量UI冒烟）、桌面（基础单测+严格打包冒烟）、后端全量（真实 PostgreSQL + Dovecot IMAP，0 跳过）以及真实全栈端到端测试；
    2. 定时与手动扩展演练：真实跨库恢复演练、三版本历史数据平滑升级迁移、多进程 Worker 故障恢复、确定性大邮箱基准与资源测量；
- **环境隔离**：CI 与本地环境共享统一的运行时与命令入口，并行测试任务使用独立数据库与隔离目录，退出时严格清理，杜绝跨任务污染。
- **状态变更注记（2026-10-27 补）**：本条已被本地门禁决策取代，不再是现行决策。GitHub Actions 工作流已于 2026-10-26 在提交 `49a6d024` 移除，现行口径以 [testing.md](testing.md)「无远程 CI」为准：仓库不运行 GitHub Actions 远程 CI，测试门禁由开发者在本地执行。本条仅作历史记录保留。
