# p046 邮件列表同步按钮改造为增量同步、设置页收敛全量同步及状态指示优化

- 来源：用户提出
- 内容：
    1. 列表右上角同步按钮改造为增量同步：
        - 邮件列表右上角的刷新/同步按钮行为由触发重型全量结构同步，改为触发当前视图对应账号/收件箱的轻量**增量同步（Delta Sync）**；
        - 鼠标悬浮提示（`title` / `aria-label`）明确区分标识，提示为“增量同步”（例如“增量同步（检查新邮件）”，同步中提示“正在增量同步…”）。
    2. 全量同步入口收敛至设置界面：
        - 全量结构同步（重新发现所有文件夹与深层对齐）移出邮件主界面，仅在“设置 - 账户管理”中提供（提供单个账号及全部账号的“全量同步”按钮）；
        - 鼠标悬浮在设置界面的全量同步按钮上时，明确提示为“全量同步（重新扫描全部文件夹与元数据）”。
    3. 状态反馈收敛与去除冗余横条：
        - 列表右上角同步按钮在同步进行中保持旋转动画（`spin`），完成或空闲时停止旋转；
        - 移除邮件列表顶部弹出的“已触发全量同步”、“已触发账户同步”等非异常横条提示（`list-note`），统一以右上角按钮旋转状态为唯一直观反馈；仅在网络/同步失败时保留明确错误提示。
