# p013 侧边栏收藏夹扩展与单账号文件夹树标准术语重构

- 来源：用户提出（个人收藏扩充及标准术语对齐、单账号动态文件夹树呈现）
- 内容：
    1. 侧边栏「个人收藏」（Favorites）术语与类目调整：
        - 术语重构：原“所有收件箱”更名为“**所有收件**”；原“所有已发邮件”更名为“**已发邮件**”；保留“所有未读”；
        - 新增 3 个全局聚合入口（支持折叠展开各账户）：
            - **草稿箱**（`folder_role='drafts'`）
            - **废纸篓**（`folder_role='trash'`）
            - **垃圾邮件**（`folder_role='junk'`）
    2. 单个账号内文件夹树与标准术语（API-Driven 动态呈现）：
        - 严格遵循真实能力驱动：仅渲染官方 API 实际返回并入库的文件夹，官方协议不支持的绝对不予展示（如 Gmail 账号绝不展示“归档”）；
        - 标准角色展示术语严格规范：
            - `inbox` -> **收件箱**
            - `sent` -> **已发送**
            - `drafts` -> **草稿箱**
            - `trash` -> **废纸篓**
            - `junk` -> **垃圾邮件**
            - `archive` -> **归档**（仅 Graph 及具备物理归档的 IMAP 展示）
            - `other` -> 远端用户自定义文件夹原生名称
        - 各账户节点支持独立折叠展开（`.account-expand` 与 `.folder-tree`），点击对应项切换邮件列表检索范围。
    3. 后端协议映射与检索支持：
        - 修复 `src/mail_core/providers/imap.py`：补齐 RFC 6154 SPECIAL-USE 属性解析（`\Sent`, `\Drafts`, `\Trash`, `\Junk`, `\Archive`）与国内主流邮箱中文名（“草稿箱”、“已删除/废纸篓”、“垃圾邮件”、“归档”等），确保 5 大通用角色与归档精准映射；
        - 确保 `/api/mail/inbox?folder_role=...` 支持对新增角色（`drafts`, `trash`, `junk`, `archive`）的跨账户与单账户游标分页检索。
