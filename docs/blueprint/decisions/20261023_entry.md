# 006 写回批次自动续跑与本地字段意图收敛保护（t012）（2026-10-23）

- **背景**：此前批次尾部使用同键入队被运行中的 claimed 任务去重吞掉，导致超过 20 条操作中断；旧同步快照覆盖本地读状态；且 autoflush=False 导致统计读取早于 ORM flush。
- **决策**：
    1. claimed 任务捕获后续唤醒并在 complete 后原子派生新 pending 任务，保证批次自然排空；
    2. 入站同步基于 RemoteOperation 待处理状态及 60 秒写回完成保护窗口仲裁，保护本地未收敛意图不被旧快照覆盖；
    3. 文件夹统计计算前强制 flush 会话，杜绝 SQL 聚合与 ORM 状态顺序漂移。
