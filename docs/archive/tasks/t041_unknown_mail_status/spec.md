# Task spec

## 背景

p024 复现首次同步缺少邮件状态时，非空 false 默认值把未知状态保存为确定事实。旧库无 flag 列也被硬编码 false。

## 契约区

### 范围

- 持久化、迁移、API、前端和统计保留未知 read/flag/attachment 状态；未知值不冒充未读、无附件或未标星。

### 非范围

- 不批量重写历史邮件，不删除运行容器数据，不改服务商原始摘要，不执行生产部署。

- [x] AC-001：服务商未返回 read/flag/attachment 时，新邮件对应字段保存 null；已存在明确状态不被未知更新覆盖。
- [x] AC-002：API 与前端保留状态 null，不将未知读状态呈现为未读或自动执行已读写回；用户明确操作可设置真实布尔状态。
- [x] AC-003：未读统计包含未知读状态邮件时返回 null，不返回忽略未知邮件后的部分和；已知总数仍准确。

- [x] AC-005：迁移保留已有数据；降级无法表示 null 时明确拒绝，不擅自回填 false；生成契约无漂移。

### 风险与回退

- 风险：调用方将 null 误当 false 或把部分响应当完整快照；测试覆盖首次插入、已有数据与显示分支。
- 回退：保留历史事实值；迁移降级遇未知值拒绝造假，可回滚应用并从部署前备份恢复数据库。

### 依赖与约束

- 用户明确要求直接在 main 修复；登记引用不冒充工具链 worktree 执行状态。
