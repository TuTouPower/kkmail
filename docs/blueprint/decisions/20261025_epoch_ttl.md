# 005 会话 epoch 废除 TTL 缓存并恢复数据库权威实时校验 (A13)（2026-10-25）

- **背景**：此前为减少认证查询曾引入进程内 5 秒 session epoch 缓存，但该放行窗口导致跨进程会话吊销与改密存在最长 5 秒的非即时窗口。
- **决策**：Adoption A13 彻底废除 5 秒 TTL 缓存放行窗口。所有认证请求统一由数据库已提交的 `session_epoch` 权威实时校验；数据库连接故障、查询失败或凭据记录缺失时严格 fail-closed 抛出 `AuthConfigError` 拒绝认证。
- **安全边界**：彻底消除跨进程传播延迟，改密与登出跨进程即时生效；数据库作为 session epoch 的唯一权威源，故障或缺失记录时零放行（fail-closed）。
