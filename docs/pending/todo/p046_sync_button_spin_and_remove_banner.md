# p046 邮件列表同步状态收敛至右上角同步按钮旋转动画并移除顶部提示条

- 来源：用户提出
- 内容：
    1. 交互状态收敛：
        - 邮件列表右上角刷新/同步按钮（`RefreshCw`）在同步进行中时保持旋转动画（`spin`）；在同步完成或未在同步时立即停止旋转；
        - 同步状态反馈完全以右上角同步按钮是否旋转为唯一直观指示。
    2. 移除冗余横条提示：
        - 移除邮件列表顶部弹出的“已触发全量同步”、“已触发账户同步”等非异常状态提示条（`list-note`）；
        - 同步失败或网络异常时仍保留明确的错误提示（或通过统一轻提示/错误态反馈）。
- 处理：未开
