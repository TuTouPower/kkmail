# p045 侧栏账号与分组搜索框支持点击外部区域自动隐藏

- 来源：用户提出
- 内容：
    1. 交互现象：
        - 当前在侧边栏点击“账号列表”或各分组的搜索图标按钮后，会展开内嵌搜索框；
        - 用户在输入搜索词或点击页面其他区域（失焦/点击外部）后，搜索框持续常驻展开，无法通过点击外部区域自动收起隐藏。
    2. 期望改进：
        - 增加点击外部区域（click-outside）及失焦关闭逻辑：当用户点击搜索框及对应搜索触发按钮以外的区域时，自动隐藏该搜索框并恢复默认折叠/视图；
        - 保留现有的按 Esc 键关闭、点击清空按钮或再次点击搜索按钮收起的交互机制；
        - 覆盖“账号列表”主搜索框与所有分组内部的独立搜索框。
- 处理：未开
