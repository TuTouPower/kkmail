# p062 侧栏分组与账号列表操作栏规范化（移除数字统计、展开折叠目录树与组内排序）

- 来源：用户提出
- 内容：
    1. 移除分组数字统计：彻底去掉每个分组标题右侧的账号数量统计数字展示（`.tree-count`）。
    2. 分组右侧按钮栏规范化（固定排布顺序）：
        - ① 搜索按钮（`Search`）
        - ② 三个点操作菜单（`MoreHorizontal`）
        - ③ 全部展开 / 全部折叠账号目录树按钮（`ChevronsUpDown` / `ChevronsDownUp`）
        - ④ 分组内排序按钮（`ArrowDownWideNarrow`，恢复该组内账号的默认排序，交互与账号列表保持一致）
    3. 账号列表右侧按钮栏规范化（固定排布顺序）：
        - ① 搜索按钮（`Search`）
        - ② 新建分组按钮（`FolderPlus`）
        - ③ 全部展开 / 全部折叠账号目录树按钮（`ChevronsUpDown` / `ChevronsDownUp`）
        - ④ 账号列表排序按钮（`ArrowDownWideNarrow`，恢复账号列表默认排序）
    4. 全部展开 / 全部折叠按钮行为逻辑：
        - 仅控制该作用域下账号内部的「文件夹/目录树」展开与折叠（作用域隔离：分组按钮仅作用于组内账号，账号列表按钮作用于列表内账号）。
        - 判定准则：目标账号集合中若存在任意账号目录树处于折叠状态，点击执行「全部展开」；若所有账号目录树已全部展开，点击执行「全部折叠」。
        - 父级联动：执行全部展开或全部折叠时，若当前分组或账号列表大区块自身处于折叠闭合状态，自动联动将其展开，确保账号行在视图中始终可见。
        - 视觉反馈：根据当前状态动态切换展开与折叠图标及对应 Tooltip / `aria-label`。
- 处理：main
