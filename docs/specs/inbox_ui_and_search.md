# 收件箱交互、侧栏组织与检索技术规范 (Inbox UI, Sidebar & Search Specification)

本文档定义 kkmail 前端三栏式阅读体验、侧栏组织架构、游标深翻页、全文检索与安全沙箱渲染技术规范。

______________________________________________________________________

## 一、 界面拓扑与平台外壳规范

系统采用现代化的三栏响应式邮件客户端架构（侧栏导航、邮件列表、详情阅读器）：

### 1. 响应式布局与移动端断点

- **宽屏桌面模式**：侧栏折叠时完全从 DOM 与网格轨移除，释放水平空间；列表标题行常驻侧栏恢复入口，展开时支持鼠标连续拖拽调整分割条宽度并持久化偏好。
- **移动端断点 (≤760px)**：侧栏自动转为覆盖式抽屉（Drawer）；遮罩点击、Escape 按键及导航项选中均可自动关闭抽屉并安全恢复焦点。抽屉状态与桌面折叠偏好相互独立。

### 2. 桌面 Electron 与原生标题栏集成

- **平台识别**：桌面特性仅通过 Electron Preload 暴露，禁止通过 `?shell=desktop` 等 URL 参数伪造桌面能力。
- **macOS 原生交通灯**：采用系统原生无边框标题栏；侧栏展开/收起按钮与原生交通灯水平相邻且处于 `no-drag` 区域，其余空白标题栏保留窗口拖动能力；窗口背景跟随系统主题，杜绝冷启动闪白。
- **Windows / Linux**：保留操作系统标准窗口框架与原生控件。

## 二、 侧栏组织架构与导航状态

侧栏按“所有账号”、“用户自定义分组”与“账号列表”三个层级组织导航：

### 1. 结构层级与分类入口

- **所有账号区**：聚合展示收件、未读、已发、草稿、废纸篓和垃圾邮件六类全局快捷分类。展开各分类可下钻到单账号入口。
- **自定义分组区**：用户可创建单层账户分组，分组具有与全局相同的六类分类入口，范围严格限制于当前分组成员。
- **账号列表区**：展示全部邮箱账号及其底层真实文件夹树（基于纵向流式排版渲染在账号标题正下方，缩进保持 24px 阶梯几何基准）。IMAP `\NoSelect` 父目录作为不可点击结构节点呈现，不显示未读标记，其子目录保持正常嵌套与导航。

### 2. 布局快照与原子持久化

- 账号全局排序、各组成员归属及组内排序分别持久化在服务端；
- 侧栏拖拽调整归属与顺序时，前端生成包含版本号（`revision`）的完整快照，服务端在 PostgreSQL Advisory Lock 事务下执行 CAS 原子校验，冲突时返回 HTTP 409 并刷新权威状态。

### 3. 侧栏局部搜索

- 分组与总列表提供独立搜索框；
- 支持对启用账号的邮箱、域名、显示名称及别名进行即时过滤；搜索状态仅保存在组件内存中，关闭搜索恢复原始展开状态，过滤期间禁止拖拽。

### 4. 操作栏统一规范与外部点击自动收起

- **操作栏按钮序列**：
    - 分组行（从左至右）：`搜索`（`SB21`）$\\rightarrow$ `三个点操作菜单`（`SB22`）$\\rightarrow$ `全部展开/折叠目录树`（`SB23`）$\\rightarrow$ `组内恢复默认排序`（`SB24`）；分组行不展示账号数量数字统计；
    - 账号列表行（从左至右）：`搜索`（`SB17`）$\\rightarrow$ `新建分组`（`SB18`）$\\rightarrow$ `全部展开/折叠目录树`（`SB19`）$\\rightarrow$ `恢复默认排序`（`SB20`）；
    - 全部展开/折叠目录树仅控制账号内部文件夹树展开状态，且在目标存在折叠时全部展开并联动展开父容器，全展开时全部折叠。
- **外部点击自动收起（Click Outside Dismiss）**：
    - 当新建分组行内表单（`SB18`）、分组操作弹出菜单（`SB22`）或分组重命名表单处于激活状态时，监听鼠标/指针外部点击（`pointerdown`）；
    - 点击发生在表单或菜单外部任意区域时，自动安全收起浮层并清空未提交输入；与键盘 `Escape` 退出逻辑保持一致。

## 三、 邮件列表展示与游标分页

1. **Keyset 游标无限滚动**：
    - 邮件列表按默认 50 封/页加载（最大支持 200 封/页）；
    - 基于 `useInfiniteQuery` 与 Keyset 游标实现“触底自动加载”；列表底部进入 `IntersectionObserver` 视口后自动流式追加下一页，杜绝全屏刷新或重置滚动位置。
2. **统计权威与未知状态**：
    - 列表头部展示权威邮件总数（常规视图来源于 `folder_stats`，搜索来源于 `search.total`）；
    - 若某目录包含未知读状态（`is_read: null`），未读数严格显示为未知（`-`），禁止以 0 或部分和冒充。
3. **列表交互与右键快捷菜单**：
    - 支持多选、右键上下文菜单（查看详情、标为已读/未读、星标、移入废纸篓）；
    - 删除操作采用乐观更新立即从当前列表移除，后台异步同步，不阻断浏览。

## 四、 全文检索与即时过滤

1. **检索引擎与触发规则**：
    - 后端基于 PostgreSQL 全文检索 (FTS) 与 Trigram 索引；
    - 前端搜索框检测到 CJK 中文字符（`[\u4e00-\u9fa5]`）时即时触发检索；纯英文或数字输入采用 250ms 防抖并要求最低 2 个字符阈值。
2. **查询 Scope 严格隔离**：
    - 全文检索接口（`GET /api/mail/search`）支持全局、单账号、分组或精确文件夹作用域；
    - 前端查询缓存键严格按 `[scope_type, scope_id, query, filter]` 隔离，切换导航彻底重置搜索状态，杜绝跨视图数据串扰。

## 五、 邮件阅读器与沙箱安全渲染

1. **正文净化与 CSP 无脚本沙箱**：
    - 邮件 HTML 富文本正文必须经 DOMPurify 严格过滤危险标签与属性；
    - 必须在带有 CSP 约束的无脚本 `iframe`（`sandbox="allow-popups allow-popups-to-escape-sandbox"`）中通过 `srcDoc` 渲染，严禁使用 `dangerouslySetInnerHTML`，严禁开启 `allow-scripts` 或 `allow-same-origin`；
    - 邮件所有超链接自动注入 `target="_blank"` 与 `rel="noopener noreferrer"`，点击时在系统默认浏览器打开。
2. **正文数据源与错误可见性**：
    - 正文区域严格使用邮件详情接口的 `body` 数据源，禁止使用列表预览或摘要回退；
    - 若邮件发生 MIME 解析损坏，界面以横幅展示解析失败状态与脱敏原因；若同时存在部分可读正文，则在横幅下方继续渲染正文，不阻断阅读。
3. **工具栏与邮箱地址复制**：
    - 阅读器顶部工具栏操作居中排布，已读/未读按钮动态展示当前相反状态并支持快捷切换；
    - 发件人、收件人与抄送人地址通过专用控件提供点击复制功能，复制内容为标准纯地址文本，提供约 2 秒成功反馈。
4. **深色模式智能反转与单信原色切换 (t065)**：
    - 深色模式下且邮件分类为浅色（`light`）时，默认在 iframe 内部注入智能反转滤镜（`filter: invert(100%) hue-rotate(180deg)`），白底翻转为深底同时保持超链接等品牌色相；
    - 对图片（`img`）、视频（`video`）、画布（`canvas`）与矢量图像（`picture`）进行二次反转还原色彩，并附带微弱浅色发光轮廓（`drop-shadow`）保护透明背景深色 Logo；
    - 移除浅色邮件突兀的纯白外层纸张卡片，使其与阅读器深冷青灰主背景自然融合；
    - 在阅读器顶部工具栏提供「原样视图 / 深色视图」切换按钮（`MR11`），供用户针对单封邮件即时切回发件人原始排版；
    - 通用设置提供「邮件正文深色渲染」默认偏好选项（「智能深色」与「保留原色纸张」），持久化于本地存储；浅色模式下保持发件人原始排版且工具栏切换按钮隐藏。
5. **远程图片安全代理与零外部出网 (t068/t069)**：
    - 正文沙箱 iframe 与主应用外壳 CSP 策略严格锁定为 `'self' data: cid:`，全站全程无浏览器直连外部出网，保护用户真实 IP 与网络隐私；
    - 邮件远程图片默认拦截并展示防追踪提示条；放行发件人或单封邮件后，后端为正文外部图片签发确定性 HMAC Token 代理链接，前端将 `img[src]` 与行内背景图重写为本站代理 URL；
    - 正文图片地址按 HTML5 属性语义提取：支持无引号/单双引号属性、HTML 实体解码与协议相对（`//`）补全，覆盖 `img[src]` 与行内 `background-image: url(...)`（t069）；
    - 代理端点（`/api/mail/messages/{id}/remote-images`）提供多层严格 SSRF 防护（排除私网/回环/云元数据/保留网段，直连校验安全 IP 阻断 DNS Rebinding，多 IP 按 IPv4 优先回退，限 3 跳重定向，限 10 MiB 上限，限 5s/15s 超时），对外部响应按真实文件头核验 PNG/JPEG/GIF/WebP；SVG 仅在静态安全扫描通过（无脚本/事件处理器/外部引用，≤64 KiB）后放行，否则 415；发件人白名单撤销后实时 403 阻断；
    - 代理失败按类别返回可区分状态码（400 非法目标 / 401 Token / 403 未放行 / 404 消息缺失 / 502 上游或网络失败 / 504 超时 / 413 超限 / 415 格式），响应体不泄露内部 IP 与异常栈。

## 六、 视图刷新与数据对账

1. **列表立即同步与视图刷新**：
    - 列表头部按钮为「立即同步」：对当前视图范围内的账号发起增量同步——账号 / 文件夹视图同步其所属账号（全部文件夹），分组视图同步组内启用同步的账号，全部收件视图同步全部账号；按钮图标在同步真正完成前持续旋转，成功不提示、失败才报错；同步结束后失效本地邮件列表与统计查询缓存，呈现最新数据；
    - 其余新邮件获取由后台 Worker 定时增量轮询与全文件夹 STATUS 巡检统一驱动，通过服务端 SSE 事件实时广播，前端 150ms 聚合后自动渲染新邮件。
