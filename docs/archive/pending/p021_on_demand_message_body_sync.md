# p021 查看未同步邮件时按需即时同步正文并置为最高优先级

- 来源：用户提出
- 内容：
    1. 用户在前端选中/打开某封邮件时，若该邮件正文尚未完成同步（数据库中处于 `metadata_synced` 状态，`body` 与 `parse_error` 均为空）；
    2. 提供按需即时同步能力（On-Demand Archive Sync）：触发即时拉取该邮件的 MIME 原文，将其归档优先级置为最高（抢占普通后台轮询或单封即时归档）；
    3. 前端展示正文加载状态，并在拉取解析完成后通过 SSE / 数据失效自动刷新渲染正文，避免历史邮件在后台长队列中被动等待。
- 处理：t034
