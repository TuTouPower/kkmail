# Task spec

## 背景

p073 记录一起生产慢刷新：邮件于 22:15:55 到达服务端，用户 22:15:58 在收件箱点「立即同步」，邮件 22:16:50 才落库，请求 22:16:53 才终态（55s）。原因不是邮件慢，而是账号级手动 delta 先做文件夹发现（12.5s），随后把 8 个文件夹的 delta 以同一优先级入队，由账号租约串行执行；收件箱排第 6，前端与用户都要等其余文件夹。后台 patrol/周期任务同时占用连接槽放大了等待。

本 task 只调整账号内文件夹之间的调度次序：收件箱的增量/基线任务先于同账号其他文件夹，并让 delta 在各类重新排期路径中保持原任务优先级，避免收件箱快车道在租约冲突或限流后回落到普通文件夹队列。同步范围与“等待全部文件夹完成后请求终态”的现有语义不变。

## 契约区

### 范围

- 账号级 delta 同步在文件夹发现后入队的增量任务中，收件箱（`role="inbox"`）任务先于同账号其他文件夹任务被 worker 认领并完成。
- 无已完成基线的账号初始化路径中，收件箱的基线（metadata）任务同样先于同账号其他文件夹任务被认领并完成。
- 收件箱 delta 因账号租约占用、限流、连接预算不足、临时 provider 错误、fencing 冲突或分页未耗尽而重新排期时，后续任务保持原任务的优先级，不回落为普通文件夹 delta 的优先级。
- 同步请求仍在账号内全部文件夹任务结算后才进入终态；手动/设置页/批量入口的同步范围不变。

### 非范围

- 不缩短 Graph `list_folders` 的多请求耗时，不跳过或缓存文件夹发现。
- 不改变前端「立即同步」按钮的等待语义、SSE 失效机制或列表视图范围。
- 不调整收件箱定时轮询间隔、IDLE 配额、连接槽预算或其他 job 类型的优先级分层。
- 不为用户新增优先级配置项。

## 上下文区

- 来源：p073（2026-11-04 生产证据；根因已定位为账号级文件夹发现后的 delta 入队顺序与租约串行，非邮件服务器慢）

### 有意不测

- 真实 Outlook/Graph 网络时延：不可控且与调度次序无关；用可控延迟的测试 provider 覆盖。
- 前端旋转动画与列表渲染时序：现有 `useMailCoreRealtime` 测试已覆盖 `message.upserted` 触发失效；本 task 不改前端。

### 测试策略

- 后端集成测试（多文件夹夹具 + 可控延迟测试 provider）：收件箱在 provider 返回顺序中故意置后，断言 delta 认领顺序和完成顺序为收件箱优先，且邮件在收件箱任务完成时已落库。
- 后端集成测试（无基线夹具）：断言 metadata 任务收件箱优先。
- `sync_folder_delta` 单元测试：外部持有账号租约、注入限流、容量不足、provider 临时错误、fencing 冲突和未耗尽分页，断言重新入队任务的优先级等于原任务优先级；直接调用的默认优先级保持现有行为。
- 同步请求聚合测试：多文件夹同步在全部子任务结算前保持非终态，全部结算后才终态。
- 全量回归：相关 `tests/mail_core/test_sync_mode_policy.py`、`test_sync_delta.py`、`test_sync_retry_queue.py`、`test_worker_loop.py` 与新增测试。

### 风险与回退

- 风险：收件箱优先级高于同账号其他文件夹后，频繁手动刷新可能让同账号其他文件夹的 delta 长期排在其后；账号租约与去重键会把并发收件箱任务收敛为单条在途任务，且每个请求仍会为全部文件夹入队，测试覆盖“一次请求内全部文件夹最终完成”。
- 风险：重排保留优先级可能改变既有重试的调度顺序；默认参数保持 60，仅由 handler 传入原任务优先级，影响面限定在 delta 重排路径。
- 回退：还原 `sync/engine.py` 的入队优先级与 `sync/delta.py` 的优先级参数即可，无数据库迁移、无接口契约变更。

### 依赖与约束

- 无前置 task；不改 schema、OpenAPI 或用户可见配置。
- 现有全局优先级分层（按需正文 10、写回 40、metadata 50、delta 60、周期轮询 75 等）保持不变，仅在“同账号文件夹之间”提高收件箱次序。

### Finalization 时更新的 blueprint

- `docs/blueprint/architecture.md`：在“Worker 任务调度优先级治理”相关章节补充：账号级文件夹发现派生的子任务中收件箱优先于同账号其他文件夹；delta 的租约冲突/限流/容量/错误/分页重排必须保持原任务优先级，不回落为普通 delta。
