# Task spec

## 背景

当前侧栏是个人收藏六类及组内账号，另有“未分组账户”；分类还重复展开全账号。导航改为所有账号、自定义分组、账号列表三个顶层区域，账号在总列表与所属组共用同一实体。用户补充明确：demo 与聊天只作布局和交互参考，未提及的既有功能不得删减；“工作”“个人”等仅为示例，不得写成产品预置分组。

## 契约区

### 范围

- 替换侧栏导航树并接入 t027 组织读取与 t028 分组查询，覆盖列表标题、搜索、分页、计数、批量已读与缓存。
- 统一缩进、行结构与折叠偏好，保留账号图标、本地 UI 引用、真实文件夹及深浅主题。
- “所有账号”保留现有全部六类功能按钮及行为，不能仅在单账号真实文件夹下保留相应能力来替代全局按钮；分组提供对应完整分类，统一账号快捷未读入口。

### 非范围

- 不做分组管理对话框、拖拽及标题栏按钮迁移，分别由后续 task 负责。
- 不照搬 demo 的假邮件、发信/回复/转发、归档动作或 600px 断点。

- [ ] AC-001：从上到下为“所有账号”、自定义分组、“账号列表”；三类顶层左缘一致，各区独立折叠；没有“未分组”虚拟组或原个人收藏的每类账号重复树。
- [ ] AC-002：所有账号展开保留所有收件箱、所有未读、已发邮件、草稿箱、废纸篓、垃圾邮件六个独立功能按钮及各自全局查询行为，不能按 demo 缩为四项或隐藏到账号目录；每个自定义分组提供对应六类组范围入口；账号列表始终列出全部账号，组内仅列当前成员；空组仍可导航至空结果。
- [ ] AC-003：每个账号展开可进入收件箱、inbox 未读、草稿与废纸篓；已同步的已发/junk/归档/自定义及嵌套真实文件夹仍可访问，不捏造远端不存在文件夹，不重复呈现同一个真实文件夹入口。账号标题与箭头均切换展开，选择邮件视图使用其子项。
- [ ] AC-004：所有相邻层级行首按固定 24px 增量缩进；箭头计入布局，无箭头项用同宽槽位，图标和文本按列对齐；展开树位于账号下方、后续行顺延，长邮箱不横溢或遮挡计数。
- [ ] AC-005：所有账号/组/账号/具体文件夹之间切换后，标题、列表、搜索、排序、计数及全部已读目标一致；重置选中邮件、批选与搜索，缓存按范围类型与 ID 隔离，旧请求与 placeholder 不展示其他范围邮件。
- [ ] AC-006：成员变化触发受影响组与账号的列表/搜索/统计从首屏重新查询；当前组删除后回到所有收件箱并清理选择；邮件 SSE 刷新后两处账号角标及组内计数一致，未知计数不冒充零。
- [ ] AC-007：所有账号、账号列表、自定义分组及账号展开状态在本地刷新后恢复；同一账号在总列表与组内展开状态共用，不影响分组各自折叠状态；分组或账号删除后残余偏好不形成失效导航。
- [ ] AC-008：深色、浅色、760px 两侧布局及鼠标/键盘导航可用；折叠控件 aria-expanded 与状态一致、焦点轮廓可见；稳定 UI 编号保持语义一致，消失编号废弃，新区域分配新编号。
- [ ] AC-009：改造前可用的邮件分类、真实目录、搜索、筛选、排序、分页、计数与邮件操作继续可用；以生产现有功能建立回归清单，demo 未展示不能作为删除或降级依据。
- [ ] AC-010：自定义分组仅来源于服务端已有数据及用户创建；无分组实例不出现“工作”“个人”等 demo 示例分组，也不出现对应空占位；任意合法用户组名均由数据驱动渲染，升级后原有组名与成员关系保留。

- 组件与 store/query 测试覆盖全局与分组六类完整分类、现有功能回归清单、任意用户组名、无预置分组、导航矩阵、延迟响应、空组、错误计数、偏好恢复及删除回退；保留或整体替换旧导航测试并解释语义更替，禁止就地改预期迁就实现。
- 浏览器 E2E 验证 24px 布局、长账号、多层目录和主题；真实全栈用例验证组搜索/分页/全部已读隔离。运行前端 test/type/lint/build 与 python3 scripts/run_full_stack_e2e.py。

### 风险与回退

- 风险：新导航类型漏入某个旧 accountId 推导路径，导致跨组缓存、搜索或批量操作越界；过度简化丢失真实目录。
- 回退：回退本 task 执行提交；仅清理由本 task 新增的偏好字段，不清空用户全部 localStorage。
