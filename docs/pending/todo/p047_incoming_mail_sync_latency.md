# p047 新邮件收取时延排查与同步实时性优化

- 来源：用户提出
- 内容：
    1. 现状与痛点：
        - 用户反馈外部新发到邮箱的邮件在客户端内感知与收取耗时过长，时效性偏慢；
        - 当前机制可能依赖于固定轮询间隔、后台 Worker 调度周期或缺少及时的长连接推送机制（如 IMAP IDLE / Webhook 推送）。
    2. 优化方向：
        - 梳理多账号自动同步轮询策略与调度间隔，缩短前台活跃时的轮询周期；
        - 评估并推进 IMAP IDLE 或即时通知机制落地，减少邮件到达与客户端拉取之间的时间差；
        - 优化 Worker 任务队列优先级调度，确保新收邮件的元数据同步任务（`sync_folder_delta` / `sync_folder_metadata`）获得及时执行。
