# 013 深色正文保守适配及固定浅色富文本独立纸张方案 (t006)（2026-10-22）

- **背景**：深色模式下邮件阅读区若无差别涂黑或强制滤镜反色，极易破坏第三方富文本排版和图表对比度；若全局保留白底，又会在深黑窗口中呈现刺眼通栏白块。
- **决策**：
    1. **保守分类**：通过 DOM 属性与样式解析区分无显式配色（plain）、显式浅色富文本（light）与显式深色（dark）；
    2. **无显式配色与纯文本**：深色模式下直接继承深色底色 `#1A1A1C` 与高对比白字 `#FFFFFF`，链接使用 `#0A84FF`；
    3. **固定浅色富文本**：深色模式下以独立居中纸张卡片（`.mail-paper-card`，白底、8px 圆角、16px 内边距与柔和阴影）呈现，外层阅读容器保持 `#1A1A1C`，消除通栏刺眼白块并 100% 保护富文本原文可读性；
    4. **安全红线不变**：严禁通过放宽 DOMPurify 的 script/style/meta 规则或 iframe 边界达成主题适配；拦截远程图片默认行为与 CSP 沙箱严格保持。
