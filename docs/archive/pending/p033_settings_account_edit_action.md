# p033 设置页账户列表操作列在同步按钮前增加编辑按钮

- 来源：用户提出
- 内容：
    1. 当前现状：设置页账户列表行内操作区（`settings-row-actions`）目前仅有“立即同步”与“删除账户”两个按钮，缺少直接编辑账户配置的入口。
    2. 目标方案：
        - 在账户行操作区的“立即同步”按钮前增加“编辑账户”按钮（如 Pencil 图标，附清晰 `aria-label` 与 `title`）；
        - 点击触发账户编辑模态框（支持查看/修改服务器地址、端口、SSL 设置、凭据/密码与所属分组等信息）；
        - 编辑提交后调用既有 `PATCH /api/accounts/{account_id}` 接口更新数据，并刷新账户列表与侧栏；
        - 补充 `SettingsModal` 相应单测用例，验证编辑按钮渲染、弹窗唤起与保存提交流程。
- 处理：main
