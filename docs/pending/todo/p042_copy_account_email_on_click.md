# p042 全局支持点击邮箱账户地址快捷复制到系统剪贴板

- 来源：用户提出
- 内容：
    1. 目标：在客户端所有展示邮箱账户地址的 UI 位点，提供点击快捷复制邮箱地址（例如 `[REDACTED_EMAIL]`）到系统剪贴板的能力，并给出即时轻量反馈。
    2. 涉及主要界面位点：
        - 邮件阅读器（MessageReader）：
            - 顶部工具栏中的当前归属账户标识（`.reader-location`）；
            - 邮件详情头部的发件人、收件人、抄送人邮箱地址文本；
        - 侧边栏（Sidebar）：
            - 各分类展开下的单账号导航行（`.tree-category-account`）；
            - 账号列表区域各账号主节点展示的邮箱标题与邮箱信息；
        - 账户设置（SettingsModal）：
            - 账户管理列表项中的邮箱地址文本与账户卡片；
        - 邮件列表（MessageList）：
            - 聚合收件箱/搜索等跨账号视图下展示归属账户邮箱的位点（如有）。
    3. 交互与技术细节：
        - 点击行为需与原有的导航展开/折叠、邮件选中、列表切换清晰区分或解耦（例如提供独立的复制触发热区/复制图标，或通过点击邮箱地址文本触发复制并阻止原点击穿透冒泡）；
        - 提供清晰的交互引导（如鼠标悬浮 hover 提示“点击复制邮箱地址”）；
        - 复制成功后提供轻量反馈（如 Tooltip 提示“已复制地址”或状态浮层）；
        - 适配 Electron 桌面端与浏览器 Web 端权限机制，当 `navigator.clipboard.writeText` 受限或不可用时提供优雅提示。
