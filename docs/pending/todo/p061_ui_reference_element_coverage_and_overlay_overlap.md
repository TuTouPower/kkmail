# p061 前端 UI 元素序号浮层交互控件覆盖率严重不足且浮标存在重叠遮挡

- 现象：
    1. 快捷键唤出 UI 元素序号浮层后，设置界面（特别是“分组管理”视图全部元素，以及“账户管理”中的大部分控件）无任何编号标签展示；
    2. 邮件页面（侧栏树中子文件夹行、操作图标按钮、邮件列表三段筛选 Tab、批量操作栏、卡片内旗标按钮、详情页防追踪允许加载图片横条、附件条目等）大量交互控件均缺失编号标签；
    3. 父容器（如 `<nav data-ui="ST04">`）与其首个子元素（如折叠按钮 `<button data-ui="ST01">`）同时包含 `data-ui` 时，浮标绝对定位坐标完全重合，造成视觉重叠与点击遮挡。
- 影响：
    - 侧栏导航、邮件列表、邮件详情与设置中心四大核心区域中约 90% 的交互控件（按钮、输入框、筛选下拉、Tab、树节点）无法被精准指认与复制引用，破坏了 UI 稳定编号作为反馈定位入口的完整性与可用性；浮标重叠导致部分已有编号无法识别和点击。
- 根因：
    - 交互元素打标范围缺失与设计下沉不足：
        1. 历史演进中（t011 UI 编号立项及后续分组管理、账户表单等功能迭代），`data-ui` 仅示范性标注了少数几个顶层容器或少数按钮，未系统性覆盖所有交互叶子控件；
        2. 部分编号直接标注在外层容器（如 `ST04` 标在 `<nav>`，`ST05` 标在 `<form>`），缺乏对内部具体控件的细分声明，且 `UiReferenceOverlay.tsx`（行 51-52）简单采用 `rect.top + 2, rect.left + 2` 放置徽标，导致父子元素在相同起始坐标处完全重叠；
        3. 同类位点清单：
            - 设置模块（ST）：
                - 设置导航项（账户管理、分组管理、通用）；
                - “分组管理”全部元素（新建分组按钮、未分组卡片、搜索框、分组行模板、重命名/删除按钮、查看成员按钮、新建分组输入框/提交按钮）；
                - “账户管理”主体元素（添加账户按钮、全量同步按钮、搜索框、分组/状态/域名筛选下拉框、批量操作栏按钮、全选框、每行编辑/单账号同步/删除/同步开关）；
                - `settings_account_form.tsx`（添加/编辑账户弹窗）内全部表单字段与按钮；
                - “通用”设置项（序号浮层开关、重置快捷键按钮、时区/超时保存表单控件、密码修改表单控件、退出登录按钮）。
            - 侧栏导航（SB）：
                - 账号列表顶部工具栏（搜索账号、新建文件夹/分组、排序按钮）；
                - 账号下展开的文件夹树节点（`tree-folder-row`，含收件箱、未读、已发送、草稿、归档、垃圾、废纸篓等角色及自定义文件夹）；
                - 账号行操作（复制地址按钮、展开/折叠箭头）；
                - 分组行（分组名称行、分组展开/折叠箭头）。
            - 邮件列表（ML）：
                - 顶部三段过滤 Tab（`全部` / `未读` / `已标记`）；
                - 批量多选操作栏（批量移入废纸篓、取消选择）；
                - 邮件卡片内旗标切换按钮。
            - 邮件详情（MR）：
                - 移动端/窄屏返回列表按钮；
                - 远程图片防追踪拦截横条及“仅此邮件允许加载”按钮；
                - 附件列表中的附件条目与下载按钮；
                - 发件人/收件人地址复制按钮。
- 测试缺口：
    - `src/frontend/src/lib/uiReference.test.ts` 仅校验了“注册表中的 key 与组件源码中的 `data-ui` 属性值双向一致”，对于组件中完全未打标的交互元素毫无感知，测试假绿；
    - `UiReferenceOverlay.test.tsx` 仅测试了隔离 DOM 中特定编号的展示与复制，缺少真实/完整页面下主要控件覆盖率的断言，亦未测试同坐标元素浮标碰撞/重叠避让逻辑；
    - 补测层级：
        1. 针对 `UiReferenceOverlay.tsx` 补充同坐标/父子重合元素的偏移避让断言；
        2. 针对核心交互组件补充覆盖率契约测试，断言关键操作控件必须具备 `data-ui`；
        3. 扩展 `UI_ELEMENT_REGISTRY` 注册表及对应的组件声明。
