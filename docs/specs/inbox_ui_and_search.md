# 需求规格：收件箱交互、游标翻页与全文检索 (Inbox UI and Search)

## 背景

为用户提供现代化、高性能的三栏式邮件阅读体验，支持深翻页、未读角标、多语言即时检索、安全邮件正文沙箱渲染，以及按用户自定义账号分组浏览邮件。

## 契约区

### 范围

- 聚合收件箱与单账户收件箱列表展示。
- 基于 `useInfiniteQuery` 与 Keyset 游标的“加载更多”列表翻页。
- 侧边栏对接服务端 `/api/mail/stats` 全局未读统计。
- 侧栏按“所有账号／用户自定义分组／账号列表”组织；支持分组邮件范围、分组管理、账号归属调整和独立持久排序。
- 全文检索（PostgreSQL FTS + Trigram，支持 CJK 单字即时检索与英文防抖）。
- 邮件正文沙箱 iframe 渲染与附件下载。

### 非范围

- 撰写新邮件界面。
- 浏览器端多标签扩展。
- 多组归属、嵌套分组、demo 示例分组与按 demo 名称区分的产品行为。

### 验收标准

- [x] AC-001：侧边栏未读角标单次请求服务端全局聚合统计接口，各账户及统一收件箱未读数精准呈现，不依赖前端首屏缓存推导。
- [x] AC-002：邮件列表初始加载首屏（100 封），若存在后续邮件，列表底部呈现“加载更多”按钮；点击后平滑追加后续邮件，不发生全屏闪烁或覆盖。
- [x] AC-003：在列表内删除单封邮件时，通过乐观更新从当前多页列表中平滑移除，不导致列表重查归零显示空屏。
- [x] AC-004：搜索输入框支持 CJK 中文单字（`[\u4e00-\u9fa5]`）即时触发搜索，纯英文保持 250ms 防抖与 2 字符阈值；搜索结果支持翻页累加。
- [x] AC-005：邮件富文本正文必须经 DOMPurify 净化并在带有 CSP 约束的无脚本沙箱 iframe（无 allow-scripts / allow-same-origin）中渲染，保留 allow-popups 与 allow-popups-to-escape-sandbox，所有外链自带 target="\_blank" 与 rel="noopener noreferrer"，使点击外链在浏览器新标签或系统浏览器打开，正文自身无法执行任何脚本。
- [x] AC-006：侧边栏支持平滑折叠至图标栏；侧栏与列表间分割条支持鼠标连续拖拽调整宽度并持久化。
- [x] AC-007：侧栏“所有账号”区展示收件、未读、已发、草稿、废纸篓和垃圾邮件六个独立分类入口；各分类可独立展开并导航至全局范围。
- [x] AC-008：所有账号分类展开后展示各账号入口；各用户分组有同样六类分组范围入口并仅展示当前组员；账号列表始终包含全部账号，账号和真实文件夹分类仍可访问。
- [x] AC-009：邮件详情页顶部工具栏操作按钮组水平居中对齐；已读状态按钮根据邮件状态动态显示「标为已读」/「标为未读」并执行状态双向切换。
- [x] AC-010：邮件列表支持右键上下文菜单（Context Menu），包含打开、已读未读切换、旗标标记、移到废纸篓及禁用的发信项，支持点击外部及 ESC 关闭。
- [x] AC-011：侧栏账号文件夹树（t024）采用纵向块级流排版，展开后文件夹树与加载/错误状态位于账号标题正下方，后续账号顺延排在整棵树下方无重叠错排；长名称不溢出容器且保持键盘 focus-visible 与 aria-expanded 导航可访问性。
- [x] AC-012：分组名称由用户创建或修改；创建、重命名和删除执行名称校验，删除分组只清除归属，不删除账号、凭据、邮件或附件。
- [x] AC-013：总账号列表顺序、各组成员顺序和分组顺序分别持久化；账号默认顺序按邮箱域名和完整邮箱地址升序，恢复默认不改变分组顺序或归属。
- [x] AC-014：账号可在无组与各组间移动；侧栏布局完整快照原子保存，重复、遗漏、未知 ID 或冲突归属载荷整体拒绝。
- [x] AC-015：分组 inbox、sent、drafts、trash、junk、archive 等已有支持分类、搜索、统计和全部已读均严格限制于当前成员；空组返回空结果，未知组和歧义参数不扩大范围。
- [x] AC-016：邮件范围查询缓存按全局、分组 ID、账号 ID、角色、筛选、排序和精确文件夹隔离；导航切换与成员变化清除选中状态并从首屏查询。
- [x] AC-017：所有账号区、每个自定义分组与账号列表独立折叠；账号展开状态在全局列表和组内共享，分组偏好不生成失效导航。
- [x] AC-018：侧栏通过整行拖拽完成组内排序、总列表排序、组间移动和移出；来源列表决定语义，主列表排序保持原分组归属，移动端可从设置选择归属。
- [x] AC-019：拖拽或设置保存失败后显示错误并回到服务端事实；改变归属后列表、搜索和计数按当前成员刷新，删除当前分组返回所有收件箱。
- [x] AC-020：侧栏延续 24px 层级缩进、键盘可达性、焦点轮廓、ARIA 展开状态、深浅主题、760px 移动抽屉与现有折叠、宽度调整能力。
- [x] AC-021：不创建“工作”“个人”等 demo 分组；保留全部六类全局分类、每组分类、账号快捷入口、同步真实文件夹，以及当前邮件操作与搜索能力。侧栏布局调整不得删减现有账号功能按钮。
- [x] AC-022（t032）：网页宽屏侧栏控制常驻邮件列表标题行；折叠后完整移除侧栏与网格轨，标题行和设置页均提供恢复入口，恢复时保留宽度与导航状态。
- [x] AC-023（t032）：macOS Electron 使用系统原生交通灯，侧栏控制与交通灯相邻且不占专属行；折叠后仍可恢复导航。标题栏空白区设置为可拖动，按钮区不可拖动。本次实际位移按用户明确裁定验收豁免，CUA 未观察到窗口 bounds 变化。
- [x] AC-024（t032）：Windows/Linux 保留原生窗口框架及既有窗口控件；浏览器 URL 参数不能授予桌面能力；Electron 保留 `contextIsolation`、`sandbox`、`nodeIntegration: false`。
- [x] AC-025（t032）：视口宽度不超过 760px 时侧栏以抽屉呈现；遮罩、Escape、选中导航、关闭后焦点恢复有效，跨断点时抽屉状态与桌面折叠状态相互独立。
- [x] AC-026（t032）：应用首帧绘制前读取保存的主题偏好并以系统主题作回退；Electron 窗口背景跟随系统主题，侧栏按钮颜色使用主题 token，不发生硬编码闪白。
- [x] AC-027（t051）：同账号多个文件夹拥有同一标准角色时，侧栏显示可区分名称，并保持每个远端 `folder_id` 独立导航。
- [x] AC-028（t052）：IMAP `\NoSelect` 结构节点在文件夹树中禁用打开且不显示未读数未知标记；其子目录仍嵌套显示并可导航。

### 可测试性声明

除 AC-023 的真实 macOS 窗口移动外，全部 AC 可由自动化测试验证。AC-023 的窗口移动本次按用户明确验收豁免处理，实际 CUA bounds 位移未观测。

### 风险与回退

- 风险：全局未读统计接口瞬时超时。
- 回退：前端优雅降级回各账户分别请求，不阻断主收件箱展示。

### 依赖与约束

- 依赖后端 `/api/mail/stats` 与 `/api/mail/inbox` 游标接口。
- 分组范围依赖当前 `group_id` 成员关系及邮件 inbox/search/stats/mark-all-read 接口；分组顺序和账号归属通过服务端侧栏布局接口持久化。
