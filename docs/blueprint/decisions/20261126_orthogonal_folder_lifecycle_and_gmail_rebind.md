# 2026-11-26 正交文件夹生命周期状态与系统角色 1-to-1 绑定

- **决策**：废除过载单列 `folders.sync_status`（`idle`/`paused`），在 `folders` 上采用三轴正交建模：类型 `kind`（`container`/`view`）、可选择性 `selectable`（`bool`，表达 IMAP `\Noselect` 层级命名空间节点）与远端存在性 `remote_state`（`active`/`missing`，表达 `container` 与 `view` 是否仍存在于远端目录）。同步可调度集合收敛为 `kind='container' AND selectable=true AND remote_state='active'`；用户可见统计与列表过滤收敛为 `remote_state='active'`。同时完善 `FolderRole`（补齐 `flagged`、`important`）、IMAP `\Important` 与 `[Gmail]/` 前缀剥离识别，并在目录发现阶段对单一远端系统角色执行 1-to-1 原位换绑与统一缺失收敛。
- **理由**：旧 `sync_status` 混载了「IMAP `\Noselect` 包装节点」「目录在远端已消失/切语言」和「已废除的 view 暂停标记」三种毫无关系的状态；前端又叠加文件名启发式 (`inferEffectiveRole`) 掩盖了后端缺 `Important` 角色与 `[Gmail]/重要` 切英文 `[Gmail]/Important` 后未收编旧行导致的双行重复展示。彻底拆除混合状态与前端猜测才能保证数据库、API 与侧栏单一事实来源。
- **机制**：
    1. Alembic 迁移 `20261126_0007` 原子增设 `selectable`/`remote_state` 列及 `ck_folders_remote_state` 约束，精确回填历史 `paused` 行（有子目录或 `[Gmail]` 根节点归为 `selectable=false, remote_state='active'`，其余 `container` 归为 `selectable=true, remote_state='missing'`），修正历史 Gmail `[Gmail]/Important` / `[Gmail]/重要` 为 `role='important', kind='view'`，按规范化系统角色合并历史双语言重复行（合并 `message_locations`、同步重写物理容器的 `messages.remote_id` 与在途 `remote_operations` 路径并在冲突时原子去重合并、`sync_checkpoints` 保留已完成全量基线、`folder_patrol_status`、`sync_request_targets`、`sync_request_target_jobs` 并按未知读状态传递规则重算 `folder_stats`）后删除 `folders.sync_status`。
    2. `ImapProvider` 支持 RFC 6154 `\Important` 映射为 `important`，补齐 `"Sent Mail"`/`"已发邮件"`/`"Bin"` 等系统角色并在已知角色匹配前统一剥离 `[Gmail]/` 前缀，同时移除硬编码非标准 `重要`、`所有邮件` 等中文字串猜测。
    3. `sync_account_folders` 为已知且唯一的系统角色（`sent`/`drafts`/`trash`/`junk`/`archive`/`all`/`flagged`/`important`）在「同账号唯一 `active` 消失旧行（Gmail 无 `active` 候选项时可回退唯一历史 `missing` 行）↔ 同角色唯一新增远端行」时原位换绑 `remote_id`/`name`/`kind`/`selectable`/`parent_remote_id`/`remote_state='active'`（保留 `Folder.id`、`MessageLocation`、`SyncCheckpoint`，并对物理容器原子重写 `Message.remote_id` 内嵌目录路径与在途写回 `RemoteOperation`），并在远端不再返回任何旧 `container` 或 `view` 时统一收敛 `remote_state='missing'` 并发射 `folder_deleted` Outbox 事件。
    4. `/api/mail/account-folder-stats` 契约移除 `sync_status`，改为返回 `kind` 与 `selectable`；出站写回（单封读/标星/废纸篓与批量已读）主位置严格只取可同步物理容器（`kind='container' AND selectable=true AND remote_state='active'`），无可用物理容器时不回退失效/`view`/`INBOX` 发起远端写回；前端 `Sidebar.tsx` 移除 `inferEffectiveRole` 与中英文系统名硬编码映射，直接消费 `folder.role` 与无角色限定的 `folder.selectable === false`，`MessageList.tsx` 头部统计同步忽略 `selectable === false` 节点。
- **后果**：所有下游同步调度（`worker`/`patrol`/`idle_watcher`/`delta`/`reconcile`/`sync_requests`/`label_backfill`）与统计/检索查询（`queries`/`mutations`）统一使用正交表达式与 `is_important_view()`，消除 `"paused"`/`sync_status` 歧义。
- **兼容**：零向后兼容包袱，`SyncStatus`、`Folder.sync_status` 及 API `sync_status` 字段一次性删除，不保留双写或回退枚举。
